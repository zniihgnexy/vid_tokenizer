# Archive Notes

`arxiv/` is the archive area for material that should be preserved but should
not dominate the main engineering view of the repository.

## Current Subfolders

- `legacy_notes/`: previous handoffs, exports, bootstrap notes, and older
  process-facing material

The rule is simple:

- if a file is needed to run, test, document, or review the current project,
  keep it in the active project tree
- if a file mainly explains historical thinking or older packaging state, move
  it under `arxiv/legacy_notes/`
